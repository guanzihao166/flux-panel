# Flux Panel 1.7.5

## 节点 IPv4 / IPv6 通信地址

- 节点监控页可分别编辑 **IPv4 服务器地址** 与 **IPv6 服务器地址**。
- 两个地址均为可选项，但至少需要填写一个；可只填 IPv4、只填 IPv6 或同时填写。
- 历史 `server_ip` 字段保留为兼容地址，旧节点和既有转发不会因升级中断。

## 隧道路由通信 IP

- 在“隧道管理”的隧道转发/转发端点编辑页，可为每个中继与出口节点选择通信使用 IPv4 或 IPv6。
- 提供“全部 IPv4”“全部 IPv6”快捷设置，也支持逐节点混合选择。
- 该设置只影响隧道路由中的中继和出口节点，不修改入口 IP 或入口监听地址。
- 保存时会验证所选节点确实配置了对应协议族地址；更新后会自动重建关联转发链路。

## 升级

执行 `migrations/1.7.2.sql`，该迁移会新增地址与路由模式字段，并将现有纯 IPv4/IPv6 的历史 `server_ip` 回填到相应新字段。
