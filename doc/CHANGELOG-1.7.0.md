# Flux Panel 1.7.0

## 功能

- 转发管理支持故障转移与负载均衡：
  - 可对远程多地址选择故障转移、轮询、加权轮询。
  - 可对转发端点组选择故障转移、轮询、加权轮询。
- 转发模式：
  - 直连：入口节点直接转发到目标地址。
  - 单跳转发：从入口节点通过一个转发端点组出口。
  - 链式转发：从入口节点经过中继和多个转发端点组。
- 链式转发选择：
  - 智能选择：使用转发端点自身配置的完整转发链。
  - 固定前N跳：只使用每个转发端点转发链的前 N 个中继。
  - 固定后N跳：只使用每个转发端点转发链的后 N 个中继。
- 转发限制：
  - 独立上行/下行限速（MB/s）。
  - 上下行合计限速（MB/s）。
  - 最大来源IP数。
  - 每IP最大连接数。
  - 端口到期时间。
- 隧道新增“转发端点”类型，用于组合单跳/链式转发出口。
- 端口转发界面新增活跃连接统计：
  - 连接ID、开始时间、客户端地址、目标地址、真实目标、本地地址、类型、入口服务器、转发器、上传、下载。
- agents 上报服务器 TCP/UDP 连接数量，并在系统信息心跳中附带活跃连接详情。

## 升级注意

- 面板升级到 1.7.0 后，节点端 agents 也需要升级到 1.7.0，才能使用带宽限制、连接限制、到期时间与连接统计。
- 执行 `doc/migration-1.7.0.sql` 前请先备份数据库。
